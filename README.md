# Optimización de Rutas CVRP

Proyecto académico desarrollado con Streamlit y Google OR-Tools.

## Caso de estudio

Distribución de alimentos en la Sabana de Bogotá.

## Objetivo

Minimizar la distancia total recorrida por la flota respetando las restricciones de capacidad.

## Tecnologías

- Python
- Streamlit
- Google OR-Tools
